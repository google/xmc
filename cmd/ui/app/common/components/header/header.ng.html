Search Syntax

Full-Text Search:

Use strings to search by Title, Tags, or Creator.

gemax "my experiment"

Field-Specific Filters:

Use comparators (=, !=, >=, <=) for specific fields.

  • XID: xid = 72901
  • Title: title = "My Experiment"
  • Creator: creator = user@google.com
  • Notes: notes = dropout
  • Date: created >= 2025-10-10

Special Fields:

  • Tags: tags:test
  • State: active_state = Active

Operators: Combine queries with AND, OR, and NOT (or -).

  • tags:llm AND created >= 2025-10-10
  • -tags:archive

Not Supported:

  • Wildcard searches (e.g., title="*gemini")
  • Structural searches (e.g., status.active_state = 2)
