# Answers to Explicit Reviewer Questions

Here are the resolutions to the questions raised during design preparation:

### 1. Should `privileged` and `hostNetwork` overrides be restricted strictly to accelerator workloads (e.g. pods specifying `TpuResources` or `GpuResources`)?
* **Answer**: Yes. CPU-only workloads should not be allowed to escape isolation and run with elevated security permissions or direct host network access, as this poses a significant cluster security risk. We will enforce this restriction at the API validation layer (`ValidateCreateWorkUnitRequest`).
* **Whole-JobSet Exception for Orchestrators**: To support Pathways RL/training topologies where a CPU-only orchestrator container (e.g., `pathways-head`) must run alongside TPU workers in the same JobSet and communicate with them on the host network, the validation check will be JobSet-scoped. If **any** job in the JobSet requests GPU/TPU accelerator resources, the entire JobSet is considered an authorized accelerator workload, permitting CPU-only controller/head jobs within that JobSet to opt into `hostNetwork` and/or `privileged` mode if needed.

### 2. Should we allow full `privileged: true` or instead expose targeted capability additions (e.g., `capabilities.add = ["SYS_PTRACE", "IPC_LOCK", "NET_ADMIN"]`)?
* **Answer**: We will expose **both**. Exposing `privileged: true` (guarded for TPU/accelerator training) is necessary since heavier workloads (such as MaxText or other workloads requiring direct VFIO device access) require full privileges. However, providing `add_capabilities` and `drop_capabilities` allows developers to practice the Principle of Least Privilege (e.g. adding only `SYS_PTRACE` or `IPC_LOCK` for JAX multi-node training without requiring full container escape).

### 3. Is `RunAsUser / RunAsGroup` override required alongside `privileged`?
* **Answer**: Yes. When running containers in privileged mode for host device access (such as TPU `/dev/accel*` device nodes), the drivers or host filesystem mounts frequently require running as root (`runAsUser: 0`) or under specific system groups. If we do not allow overrides, the hardcoded `runAsUser: 1000` will block root initialization and cause driver execution to fail. We will expose optional `run_as_user` and `run_as_group` overrides inside the new `PodSecurityContext` protobuf message.

### 4. Code Comment Warnings in `jobset.go`
* **Observation**: The comments in [cmd/actuator/k8s_client/jobset.go:L674-L700](file:///tmp/koder_workspaces/task_530042978/xmc/cmd/actuator/k8s_client/jobset.go#L674-L700) explicitly warn against modifying `defaultSecurityContext()` and `defaultPodSecurityContext()`.
* **Resolution**: To respect this security boundary, **we will not alter `defaultSecurityContext()` or `defaultPodSecurityContext()`**. They will remain intact and serve as the default baseline. User-requested overrides will be overlayed conditionally only when explicitly defined in the WorkUnit protobuf and validated successfully as an authorized accelerator workload.

## 2. Actuator Manifest Generation (`cmd/actuator/k8s_client/jobset.go`)

We will implement functions to construct Kubernetes security and networking configurations, combining default policies with user-submitted overrides.

### 1. New Security Context Helper Logic
```go
func buildSecurityContext(protoSC *esspb.SecurityContext) *corev1.SecurityContext {
	if protoSC == nil {
		return defaultSecurityContext()
	}
	sc := defaultSecurityContext()
	if protoSC.Privileged != nil {
		sc.Privileged = proto.Bool(*protoSC.Privileged)
	}
	if protoSC.AllowPrivilegeEscalation != nil {
		sc.AllowPrivilegeEscalation = proto.Bool(*protoSC.AllowPrivilegeEscalation)
	}

	// If privileged is true, clear the default Drop: ["ALL"] capabilities
	// unless the user explicitly requested custom capabilities.
	if sc.GetPrivileged() {
		sc.Capabilities = nil
	}

	if len(protoSC.AddCapabilities) > 0 || len(protoSC.DropCapabilities) > 0 {
		caps := &corev1.Capabilities{}
		for _, c := range protoSC.AddCapabilities {
			caps.Add = append(caps.Add, corev1.Capability(c))
		}
		if len(protoSC.DropCapabilities) > 0 {
			for _, c := range protoSC.DropCapabilities {
				caps.Drop = append(caps.Drop, corev1.Capability(c))
			}
		} else if !sc.GetPrivileged() {
			caps.Drop = []corev1.Capability{"ALL"}
		}
		sc.Capabilities = caps
	}
	return sc
}

func buildPodSecurityContext(protoPodSC *esspb.PodSecurityContext) *corev1.PodSecurityContext {
	psc := defaultPodSecurityContext()
	if protoPodSC == nil {
		return psc
	}
	if protoPodSC.RunAsUser != nil {
		psc.RunAsUser = proto.Int64(*protoPodSC.RunAsUser)
	}
	if protoPodSC.RunAsGroup != nil {
		psc.RunAsGroup = proto.Int64(*protoPodSC.RunAsGroup)
	}
	return psc
}
```

### 2. Network & DNS Policy Logic
```go
func resolveHostNetworkAndDNSPolicy(job *esspb.KubernetesJob, jsNetwork *esspb.JobSetExecutable_Network) (bool, corev1.DNSPolicy) {
	hostNetwork := false
	if job.GetPodSecurityContext() != nil && job.GetPodSecurityContext().HostNetwork != nil {
		hostNetwork = *job.GetPodSecurityContext().HostNetwork
	} else if jsNetwork != nil && jsNetwork.HostNetwork != nil {
		hostNetwork = *jsNetwork.HostNetwork
	}

	var protoPolicy esspb.DnsPolicy
	if job.GetPodSecurityContext() != nil && job.GetPodSecurityContext().GetDnsPolicy() != esspb.DnsPolicy_DNS_POLICY_UNSPECIFIED {
		protoPolicy = job.GetPodSecurityContext().GetDnsPolicy()
	} else if jsNetwork != nil {
		protoPolicy = jsNetwork.GetDnsPolicy()
	}

	dnsPolicy := corev1.DNSClusterFirst
	switch protoPolicy {
	case esspb.DnsPolicy_CLUSTER_FIRST:
		dnsPolicy = corev1.DNSClusterFirst
	case esspb.DnsPolicy_CLUSTER_FIRST_WITH_HOST_NET:
		dnsPolicy = corev1.DNSClusterFirstWithHostNet
	case esspb.DnsPolicy_DEFAULT:
		dnsPolicy = corev1.DNSDefault
	case esspb.DnsPolicy_NONE:
		dnsPolicy = corev1.DNSNone
	default:
		// Safety Default: If hostNetwork is true, default to ClusterFirstWithHostNet
		// so pods can still resolve cluster-internal service addresses.
		if hostNetwork {
			dnsPolicy = corev1.DNSClusterFirstWithHostNet
		}
	}
	return hostNetwork, dnsPolicy
}
```

## 3. API Validation Rules (`internal/validator/requests.go`)

We will restrict `privileged` and `host_network` usage in `ValidateCreateWorkUnitRequest` to prevent privilege escalation on general CPU workloads, allowing it only if any job in the JobSet requests GPU or TPU resources.

```go
func validateGatedSecurityPrivileges(wu *essmsgpb.WorkUnit) error {
	hasAccelerators := false
	jobSet := wu.GetExecutable().GetJobset()
	for _, job := range jobSet.GetJobs() {
		if job.Spec != nil && job.Spec.Resources != nil {
			if job.Spec.Resources.GetGpuResources() != nil || job.Spec.Resources.GetTpuResources() != nil {
				hasAccelerators = true
			}
		}
	}

	assertAccelerator := func(field string) error {
		if !hasAccelerators {
			return fmt.Errorf("privileged/hostNetwork access (%s) is restricted to jobs specifying GPU or TPU resources: %w", field, status.ErrInvalidArgument)
		}
		return nil
	}

	// 1. Check JobSet-wide host_network
	if jobSet.GetNetwork() != nil && jobSet.GetNetwork().GetHostNetwork() {
		if err := assertAccelerator("jobset.network.host_network"); err != nil {
			return err
		}
	}

	// 2. Check each Job
	for _, job := range jobSet.GetJobs() {
		if job.GetPodSecurityContext() != nil && job.GetPodSecurityContext().GetHostNetwork() {
			if err := assertAccelerator(fmt.Sprintf("jobs[%s].pod_security_context.host_network", job.GetName())); err != nil {
				return err
			}
		}

		if job.Spec.GetSecurityContext() != nil && job.Spec.GetSecurityContext().GetPrivileged() {
			if err := assertAccelerator(fmt.Sprintf("jobs[%s].spec.security_context.privileged", job.GetName())); err != nil {
				return err
			}
		}

		for i, initContainer := range job.GetInitContainers() {
			if initContainer.GetSecurityContext() != nil && initContainer.GetSecurityContext().GetPrivileged() {
				if err := assertAccelerator(fmt.Sprintf("jobs[%s].init_containers[%d].security_context.privileged", job.GetName(), i)); err != nil {
					return err
				}
			}
		}

		for i, sidecar := range job.GetSidecars() {
			if sidecar.GetSecurityContext() != nil && sidecar.GetSecurityContext().GetPrivileged() {
				if err := assertAccelerator(fmt.Sprintf("jobs[%s].sidecars[%d].security_context.privileged", job.GetName(), i)); err != nil {
					return err
				}
			}
		}
	}
	return nil
}
```

This helper will be invoked inside `ValidateCreateWorkUnitRequest` after iterating over and validating the individual jobs list.
