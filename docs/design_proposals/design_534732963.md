# Technical Design Proposal: Standardizing Python Virtual Environment for XMC Tooling

## 1. Objective
The goal of this proposal is to simplify, standardize, and improve the robustness of the Python virtual environment setup used for XMC automation and deployment tools. Currently, the setup strictly checks for a very specific Python version (3.13.14) and silently handles bootstrap failures, which can lead to developer friction and hard-to-debug issues.

## 2. Proposed Changes

### 2.1. Relax Python Version Requirement
Currently, `tools/setup_venv.py` warns if the Python version is not exactly `3.13.14`. We propose relaxing this to require a minimum version of **Python >= 3.10**, which aligns with the `target-version = "py310"` specified in `pyproject.toml`.

- **File**: [tools/setup_venv.py](file:///tmp/koder_workspaces/task_534732963/xmc/tools/setup_venv.py)
- **Modification**:
  - Update `check_prerequisites()` to enforce `sys.version_info >= (3, 10)` as an error (exiting the script) instead of a warning for a specific version.
  - Update help strings and docstrings that reference the strict `3.13.14` requirement.
