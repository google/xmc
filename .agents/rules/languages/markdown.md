# Markdown Documentation Guidelines

Formatting and maintenance standards for Markdown files.

---

## 1. Formatting & Structure
- **GitHub Flavored Markdown (GFM)**: Follow GFM specifications.
- **Heading Hierarchy**: Maintain logical heading levels (`#`, `##`, `###`).
- **Code Symbols & Relative Links**: Use clickable relative links (backtick string paths (e.g. `relative/path/file.md`)) for internal cross-references.

## 2. System Contracts & Sync
- **Accurate Representation**: Mirrors production specs, API interfaces, and CLI flags.
- **Synchronized Updates**: Update documentation in the exact same PR whenever contracts change.
